# Blank Canvas

Crie um projeto mínimo, com uma única página totalmente branca e vazia. Configure somente a estrutura necessária para funcionar. Não adicione textos, menus, imagens, exemplos, animações, login, banco de dados ou integrações. Quero apenas uma base em branco para desenvolver depois. Finalize após criar essa estrutura.

This project was built with [Lovable](https://lovable.dev).
